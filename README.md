# ATLAS — школа языков и перевода (концепт)

Концепт сайта языковой школы. Школа, цены и сроки вымышленные; сложность языков указана
примерно, для русскоговорящих учеников.

**Сайт:** https://iaroslaviskendirov-alt.github.io/atlas/

**Стек:** React 19, TypeScript, Vite, Tailwind CSS 4, three.js + @react-three/fiber, cobe,
country-flag-icons, framer-motion, lucide-react. Структура в стиле shadcn (`src/components/ui`, `src/lib`).

## Что внутри
- `globe-hero.tsx` — каркасный 3D-глобус на первом экране (three.js). Цвет берётся из темы,
  отрисовка останавливается вне экрана.
- `flag-globe.tsx` — глобус с флагами на cobe. Доработано:
  - флаги на видимой стороне — кнопки (`onFlagClick`);
  - `focusCode` / `focusKey` плавно доворачивают глобус к стране (поиск);
  - `activeCode` подсвечивает выбранный флаг;
  - флаги передаются пропсом `flags` — подключены только нужные страны.
- Поиск по странам и языкам («Япония», «японский»), стрелки и Enter.
- Окно курса: сложность 1–5, срок до B1, занятий в неделю, цена в группе / индивидуально,
  программа и запись на пробный урок. На телефоне — выезжает снизу.
- Каталог всех курсов от лёгкого к сложному.

Языки, страны, уровни и цены — в `src/data.ts`.

## Запуск
```bash
npm install
npm run dev
```
Публикация — автоматически через GitHub Actions при push в `main`.
